# Vitals

An executive activity dashboard plugin for [Obsidian](https://obsidian.md) to track, analyze, and visualize personal productivity, reading, writing, and study sessions directly from note YAML frontmatter.

Developed by **Siam Mehraf**.

## Features

- **GitHub-style Contribution Heatmap**: Visual activity density across the full calendar year with interactive year switching.
- **Dynamic Time Range Filtering**: Instant metrics filtering by 7 Days, 30 Days, This Month, Prev Month, This Year, Prev Year, or All Time.
- **Activity & Trend Chart**: Dual-layer Bar and Line visualization supporting both Day and Week views.
- **Category Donut Analysis**: Clean breakdown of categories with percentage distribution.
- **Geist Mono Interface**: Monospace executive dark theme styling.

## How It Works

Add standard YAML frontmatter to any markdown note you want to track:

```yaml
---
type: Writing
date: 2026-11-04
duration: 75
project: Manuscript
---
```
